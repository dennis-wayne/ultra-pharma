# Hero and artwork direction — 21 October 2026

The hero pairs an offset editorial headline with four detailed regulatory document sheets. Each sheet contains a stage title, a short descriptor and a small relevant structure: dossier review, regional adaptation, clinical/economic evidence, and ongoing obligations. There are no sample approval statuses, invented metrics or decorative technical annotations.

Paper, ink and tinted neutrals carry the composition. Teal is limited to the connecting route and interactions. Rounded pills and panels remain part of the existing identity. SVG keeps the artwork sharp and theme-aware. The artwork is illustrative; real HTML links beneath it expose every stage and destination to keyboard, touch and assistive technology users.

At desktop sizes, the headline is sized against its column and the artwork has its own gutter. Smaller layouts stack both areas. A finite entrance settles into a static scene; focus and hover change the highlighted document. The original "Precision in healthcare. Confidence in regulation." signature remains below the main title.

Supporting illustrations use the same document language only on Practice and Reimbursement. See COPY-AND-SURFACE-REVIEW.md for copy decisions and verification evidence.
